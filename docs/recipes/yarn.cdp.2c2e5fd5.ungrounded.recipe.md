1. Close the open **Settings** dialog using its button; confirm **Workspace name** is no longer visible.
2. In the **Untitled** title textbox, enter the draft name. The verified run used **Scratch Cursor Type Demo 7f3a**; confirm the title updates.
3. In the draft’s **Screen clip settings**—a per-project override, not a brand-wide default—open the **Cursor Style** combobox.
4. Choose the desired cursor type. The verified run selected **Pointer-first** instead of **Arrow-first**; confirm the combobox now shows the new value.
5. Click **Done** to commit the change and close **Screen clip settings**.
6. Open **Project actions**, then select **Screen Clip Settings...**.
7. Confirm the saved cursor style is still shown. For the verified value, **Pointer-first** should appear and **Arrow-first** should be absent.
