1. Click **New Draft** to open a draft editor. Confirm the editor shows **Project actions** and the script entry area.

2. In the draft title field, replace **Untitled** with the desired draft name. The verified run used `scratch-cursor-type-demo-20260801`.

3. In this draft’s **Screen Recording Settings**—a per-draft override, not a brand-wide default—click the **Cursor Style** dropdown, currently showing **Pointer-first**.

4. Select the desired cursor type. The verified run selected **Arrow-first**. Confirm the dropdown now reads **Arrow-first** and no longer shows **Pointer-first** as selected.

5. Click **Done** to save the setting and close the settings panel.

6. To verify the change persisted, open **Project actions**, then click **Screen Clip Settings...**.

7. Confirm the reopened **Screen Recording Settings** shows **Cursor Style: Arrow-first** for the named draft, with **Pointer-first** absent as the selected value.
